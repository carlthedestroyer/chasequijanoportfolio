Background

What Field Oriented Control Solves

Field Oriented Control (FOC) is a technique used in variable frequency drives and motor control systems, particularly for AC motors like permanent magnet synchronous motors (PMSMs) and brushless DC motors (BLDCs). The main goal of FOC is to control the motor's magnetic field in a way that maximizes efficiency and allows for precise control of torque and speed.

It does this by transforming the three-phase motor currents into a two-axis coordinate system, often called the d-q axis. This transformation allows the control of the motor to be similar to that of a DC motor, where torque and magnetic flux can be independently regulated, leading to smoother and more efficient operation. I built this test bench to learn the technique hands-on rather than only studying it in theory.

Hardware

Motor, Controller, and Automation Headroom

The rig features an Eagle Power 3018 brushless motor, selected for its higher torque and speed relative to comparable hobby BLDC motors, with an eye toward future robotics applications. For the control system, I used the ODrive S1 motor controller: an all-in-one board with a built-in magnetic encoder that gives precise motor angle readings.

The ODrive S1 also includes an onboard microcontroller that connects to a computer, and ODrive provides open-source software for motor configuration. That software supports a range of configurations for the motor and encoder, and for the type of movement desired, whether strictly position-based or a set velocity. I also integrated an STM32 development board for future use cases, such as automating the motor control without a computer in the loop.

ODrive S1 Controller

  • Built-in magnetic encoder for precise motor angle feedback
  • Onboard microcontroller with USB connection to a host computer
  • Open-source configuration software for motor, encoder, and control mode setup
  • Supports both position-based and velocity-based control modes

Reflection & Future Work

A Reusable Motor Control Test Bed

Building this rig around an all-in-one controller like the ODrive S1 made it possible to focus on understanding FOC itself, rather than spending the whole project bringing up low-level motor drive firmware. The built-in magnetic encoder and open-source tooling meant I could iterate on control mode and tuning quickly and see the effect immediately in the live telemetry.

Next steps:

  • Bring up closed-loop position control from the STM32 board directly, without the ODrive web GUI in the loop
  • Characterize torque and speed limits of the Eagle Power 3018 motor under sustained load
  • Apply the validated FOC setup to a future robotics actuator project
