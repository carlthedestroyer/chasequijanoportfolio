Exoskeleton PCB & Control System

Undergraduate Research · Rowan University · 2024

Designed a large-scale integrated PCB and complete control system for an upper-body exoskeleton. The project involved driving multiple brushless DC motors, integrating solar charging, real-time PID control via Raspberry Pi, and fabricating custom 3D-printed enclosures for a functional research prototype.

Problem

Control Electronics for Assistive Exoskeletons

Upper-body exoskeletons require precise, coordinated motor control across multiple joints — shoulders, elbows, and wrists — with real-time feedback from inertial measurement units. The control electronics must be compact enough to mount on the exoskeleton frame while handling the power demands of multiple brushless DC motors.

This research project required designing integrated electronics that could drive multiple BLDC motors simultaneously, process IMU data for real-time position feedback, and operate from a solar-charged battery system for extended autonomous use. The system also needed a debug/status display and wireless data logging capability.

Hardware

Integrated Control Board & Sensor Network

Main Control PCB

Designed a large-format custom PCB in KiCad that serves as the central control hub for the exoskeleton. The board integrates multiple BLDC motor driver stages, a Raspberry Pi compute module interface with GPIO header, an OLED display for real-time status feedback, and a complete power management subsystem with solar charging input.

8-IMU Sensor Array

Built a multi-sensor data acquisition system using 8 BNO085 IMU sensors connected to a Teensy 4.1 via custom UART drivers. Implemented SLIP protocol framing for reliable communication over RS485 transceivers, enabling distributed sensor placement across the exoskeleton frame with robust noise rejection.

Power System

The power subsystem supports both direct solar panel input and rechargeable battery operation, with appropriate voltage regulation for the logic-level components (3.3V/5V) and motor drivers (higher voltage rails). Solar charging enables extended outdoor testing sessions without manual recharging.

Enclosure & Mounting

Designed and 3D-printed custom ABS enclosures to protect the electronics and mount them securely to the exoskeleton frame. The enclosure design accounts for heat dissipation from the motor drivers and provides access to debug ports and the OLED display window.

Software

Real-Time Motor Control & Data Acquisition

The control software runs on the Raspberry Pi in Python, implementing PID control loops for each motor joint. IMU data from the 8-sensor array feeds into the control loop to provide real-time position and orientation feedback, enabling smooth joint tracking and trajectory following.

The Teensy 4.1 handles the low-level sensor communication — custom UART drivers for the BNO085 IMUs with SLIP protocol framing ensure reliable data delivery over the RS485 physical layer. Sensor fusion algorithms combine accelerometer, gyroscope, and magnetometer data to produce stable quaternion orientation estimates for each limb segment.

The OLED display provides real-time feedback on motor states, battery voltage, solar charging status, and sensor health — critical for field testing and debugging without a laptop connected.
