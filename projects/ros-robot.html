Overview

Autonomous Perception on a Mobile Base

I developed an autonomous robot running ROS 2 Iron on a Linux-based mini PC. It uses a Teensy microcontroller to control the drive motors via a stepper driver breakout board. The navigation system integrates an RPLiDAR A1 and an Intel RealSense depth camera, which uses point cloud mapping for environmental awareness.

A 22.2V 6000mAh LiPo battery powers the system, with a step-down voltage regulator managing power for the primary electronics and computer. The robot also features a custom cooling solution with 10mm fans to handle thermal management for the onboard mini PC.

Power & Thermal

  • 22.2V 6000mAh LiPo battery as the main power source
  • Step-down voltage regulator for electronics and computer power rails
  • Stepper driver breakout board between the Teensy and drive motors
  • Custom cooling solution with 10mm fans for sustained compute load

Navigation & Mapping

RPLiDAR and RealSense Point Cloud Mapping

The RPLiDAR A1 provides a 360-degree planar scan of the environment, used for localization and obstacle detection. The live capture below shows the LiDAR sweeping a room, with the white line marking the current scan angle and red points marking detected surfaces.

The Intel RealSense depth camera complements the 2D LiDAR scan with a full RGB point cloud, giving the robot a 3D understanding of the space it is navigating, including furniture and other obstacles outside the LiDAR's scan plane.

Reflection & Future Work

From Sensor Fusion to Full Navigation

Getting the RPLiDAR and RealSense streams both publishing cleanly into ROS 2 was the biggest early hurdle. Once both sensor pipelines were reliable, combining a 2D planar scan with a full 3D point cloud gave a much more complete picture of the robot's surroundings than either sensor alone.

Next steps:

  • Bring up full SLAM and autonomous waypoint navigation using the existing sensor stack
  • Fuse the RPLiDAR and RealSense data into a single occupancy map
  • Validate thermal performance of the mini PC and cooling system during extended mapping runs
